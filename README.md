# 行业有效量价因子与行业轮动策略(复刻 + 生产化改造)

基于 Tushare 代理的可运行复刻版,并由 2026-09 一轮系统性改造升级为**参数化、带完整风控与仓位闭环**的月度行业 ETF 轮动系统。

> ⚠️ **2026-09-11 数据修复公告**:`fund_daily` 为不复权价,历史数据含 414 处**份额折算/拆分假跳变**(曾让持有跨折算日的组合吃 -90% 假损失)。现已接入 `fund_adj` 复权因子前复权(修复后全部历史数字重算,见下);此前任何版本的结论均已失效。

## 最终定版口径

| 层 | 设置 |
|---|---|
| 数据 | Tushare 代理 `https://tu.brze.top`(2026-09-29 前完成迁移);ETF 日线 **2014-01-02 起,fund_adj 复权** |
| 排序截面 | 默认 `--pool sector`(每行业 1 只);可 `--pool top2/all` 扩截面(126 只) |
| 调仓节奏 | **月度**(每月首个交易日重选,整月锁仓) |
| 选券规则 | 打分 Top5 + **一行业一席**;宽基占席门槛:宽基最高分须比第 K 名行业分数高 **80%** 才可入场 |
| 权重方案 | **波动率倒数**(1/20日年化波动,单只≤35%) |
| 风控层 | **组合回撤止损 + 反弹分档建仓**(见下) |

策略一句话:**模型负责挑行业(弱信号),规则负责管风险(强纪律);选券按月,仓位按日。**

## 回撤/仓位状态机(核心机制)

以**纸面净值**(永远满仓假设的虚拟策略净值)回撤为唯一仓位信号,三档 + 阶梯:

```
纸面回撤 ≥ -10%   → 100% 满仓(波动率倒数权重)
-15% ~ -10%      →  50%
  < -15%          →   0%,并记录谷底;从谷底反弹 +12%/+24%/+36%
                     → 逐档建至 25%/50%/75%(反弹分档建仓)
```

灵感来源:GitHub `ghostcode/btd-calculate`(回撤分档)× `jiangkzheng-rgb/dingTou-reminder`(复合加仓信号)。这个闭环把"跌有刹车、涨有油门"放进同一个状态机,解决了传统回撤止损"27 连月空仓"的再入场滞后问题。

## 回测结论(2021-01-04 → 2026-09-08,复权修复后)

| 口径 | 累计 | 年化 | 最大回撤 | Sharpe |
|---|---:|---:|---:|---:|
| 等权 + 满仓(原始复刻) | +4.06% | +0.7% | -46.1% | 0.14 |
| 等权 + Old MA60 闸门 | +15.70% | +2.7% | -26.2% | 0.24 |
| **最终定版(回撤止损+阶梯+波倒权重)** | **+121.26%** | **+15.63%** | **-11.55%** | **1.03** |
| 扩截面 126 只(`--pool all`,对照) | +394.37% | +33.94% | -10.77% | 1.64 |

分年(定版,止损后):2021 +29.1% / 2022 +2.8% / 2023 -0.4% / 2024 +18.8% / 2025 +18.4% / 2026 +19.0%。
对比沪深300 同期 **-12.2%**。

模型 IC 仅 0.033(ICIR 0.12)——已实测滚动重训/Rank 标签/Rank 特征等增强手段均无效(见周报 v12 附录),策略的系统收益来自**分散+止损+恢复纪律**,而非模型排序,故不在 IC 上继续过度工程。

**风险声明**:所有结论来自同一段回测样本;参数在本样本内选择,真实表现以实盘分段验证为准;2024-10-08 这类单日 +30% 的跳空对累计收益贡献显著,实盘未必能按开盘价成交。

## 每月调仓操作(实盘流程)

每月首个交易日收盘后:

1. 运行 `python reproduce_tushare.py`(一键:数据增量→因子→模型→调仓→权重→风控)
2. 读 `artifacts/tushare_repro/strategy_returns.csv` 最后一行的 `holdings`/`weights` → 得到目标组合
3. 读 `artifacts/tushare_repro/filtered_strategy.csv` 最后一行 `exposure` → 得到总仓位(100%/50%/0),总仓位即时变化都读该文件
4. **资金流验证器监控**(`fundflow_check.csv`,`--fundflow-warn 0.10`):
   - 输出最新持仓的 20 日 ETF 份额变化率;流入 ≥10% 的持仓标"拥挤警示"
   - 实测依据:份额 20 日变化率对未来收益 pooled IC = **-0.0655(反向)**——申购踊跃=拥挤=未来跑输
   - 定位:只做验证提示,不改选券与权重(实证中 >10%+降50% 的组合级改善依赖少数事件月,不足以纳入默认)
5. **入场建仓(可选规则)**:
   - 默认次日开盘一次建仓
   - 可选:**挂"信号收盘 × 0.98"限价等回调,10 个交易日未成交改市价**(脚本自动生成 `limit_orders.csv`)
   - 实测复核:69 次调仓里限价单月均改善仅 **+0.28%/中位数 0**,47% 的月份才会出现 2% 内回调——**优势不稳定,不构成默认执行准则**;真正吃到差价的是少数出现深回调(high vol月)的月份
   - 诊断背景:入场价平均落在月内最高点的 96.3%,72% 月份买在月内高 5% 以内——等回调是新入场的可选优化的第一步,不是系统性收入
5. 按目标执行调仓;月中任何一天的仓位变化同样由该文件的 `exposure` 列给出

## 关键 CLI 参数

```
--rebalance-freq monthly|signal|daily    # 调仓节奏
--pool sector|top2|all                   # 排序截面
--weighting equal|rank|inverse-vol       # 权重方案(默认 inverse-vol)
--max-weight 0.35                        # 单只权重上限
--broad-min-edge 0.80                    # 宽基占席门槛
--risk-layer dd-stop|ma-gate|none        # 风控层(默认 dd-stop)
--dd-half-at -0.10 --dd-flat-at -0.15    # 止损阈值
--rebound-ladder "0.12:0.25,0.24:0.50,0.36:0.75"   # 反弹分档
--ma-filter half|flat|none --ma-window 60          # ma-gate 子选项
```

## 已知注意事项

1. 复权依赖 `fund_adj`;若某 ETF 复权因子缺失,其价格序列可能残存跳变(已抽检未见)
2. 成交量/成交额未复权,折算日的量能类因子会受一次性扰动
3. 训练期固定 2014→2019(已实测滚动重训等手段在本截面无效)
4. 所有调仓按收盘信号、次日执行;实盘滑点与折价溢价未建模
