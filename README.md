# 行业有效量价因子与行业轮动策略

基于 Tushare 的可运行复刻版，覆盖两层内容：

- 原始研报思路复刻：行业/主题 ETF 池 + 192 个量价因子 + 月度 Top5 轮动
- 增强版研究：在 Top5 之上叠加 ETF 短期趋势二次打分与 `CSI300 60日均线` 风险过滤

这个仓库保留两套结果口径，不混在一起下结论。

## 结论先看

### 1. 主回测口径：`2019-01-02` 到 `2026-05-06`

这套口径用于回答“原始行业轮动策略长样本是否稳健”。

- 策略：原始行业轮动
- ETF 池：`28` 只
- 累计收益率：`186.40%`
- 年化收益率：`16.09%`
- 最大回撤：`-23.79%`
- Sharpe：`0.74`

这版是主结论，因为：

- 样本更长
- ETF 池规模还合理
- 不依赖额外增强模块

### 2. 增强验证口径：`2021-01-04` 到 `2026-05-06`

这套口径用于回答“近几年市场里，增强模块是否能提高收益回撤比”。

三版对比如下：

| 版本 | 年化收益率 | 最大回撤 | Sharpe |
|---|---:|---:|---:|
| 原始行业轮动 | `1.75%` | `-40.88%` | `0.20` |
| ETF二次打分 | `7.18%` | `-57.38%` | `0.39` |
| ETF二次打分 + `60日均线清仓` | `9.23%` | `-29.13%` | `0.56` |

这版说明：

- 单独加二次打分，收益提高，但回撤会放大
- 再叠 `CSI300 60日均线清仓` 后，收益继续提高，同时回撤明显收敛

## 为什么保留两套口径

两套口径解决的是不同问题。

- `2019起原始行业轮动`：看长样本稳健性
- `2021起增强版`：看增强模块在近几年市场里是否有效

把增强版直接外推到 `2019-2026` 并不成立。我们实测后发现：

- `2019起` 原始行业轮动本身已经很强
- 同样的增强模块放到更长样本里，并没有继续提升长期表现

所以最终表述应该是：

- 长样本主结果，以 `2019起原始行业轮动` 为准
- 当前市场环境参考，以 `2021起增强版` 为准

## 为什么 `二次打分 + 60日均线` 在 `2021` 之后有效

原因主要有三点：

1. `2021-2026` 的行业切换更快、更碎
   原始月度 Top5 更容易出现“方向选对但买点偏差”的问题。

2. ETF 二次打分解决的是“Top5 内部怎么选”的问题
   它不是替代行业轮动，而是在 Top5 内再做一次短期强弱筛选。

3. `CSI300 60日均线` 起到了风险闸门作用
   在弱市中直接清仓，减少了高波动阶段的无效暴露。

## 现阶段更适合用哪一个

如果目标是公开复刻、强调稳健性，优先看：

- `2019起原始行业轮动`

如果目标是贴近当前市场、作为增强版参考，优先看：

- `2021起 ETF二次打分 + CSI300 60日均线清仓`

## 仓库结构

## 运行方式

安装依赖后，先跑原始行业轮动：

```bash
python reproduce_tushare.py
```

如果要做 Top5 二次打分：

```bash
python combine_etf_trend_model.py
```

如果要叠 `60日均线` 风险过滤：

```bash
python apply_market_trend_filter.py
```

如果要查看每天买了什么、卖了什么：

```bash
python export_final_trade_ledger.py
```
