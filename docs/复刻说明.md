# 行业有效量价因子与行业轮动策略

这个目录现在有一套不依赖 `qlib` 的 Tushare 复刻脚本：

- `reproduce_tushare.py`
- `scr/data_service.py`

## 复刻思路

1. 用 Tushare 抓行业/主题 ETF 日线数据
2. 按原 notebook 的定义生成 192 个量价因子
3. 用横截面回归模型对下一期收益打分
4. 每日等权持有预测得分最高的 `top_k` 只 ETF
5. 输出 IC、分组收益、策略净值曲线

## 运行命令

```bash
python reproduce_tushare.py
```

快速烟雾测试：

```bash
python reproduce_tushare.py --start-date 2020-01-01 --end-date 2021-12-31 --train-end 2020-12-31 --valid-end 2021-06-30 --max-symbols 12
```

- 数据源已切到 Tushare 代理，不再依赖原 notebook 丢失的 `scr.data_service`
